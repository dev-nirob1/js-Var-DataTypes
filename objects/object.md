# Objects #
=> Javascript e object হলো একটি  Non-Primitive(reference) Data Types. যা  related data গুলোকে structured way তে store and manage করা যায়। Objects মূলত key-value pairs এর একটি collection. যেখানে প্রতিটি key একটি unique name এবং আর সাথে একটি corresponding value থাকে।

=> An Objects in Javascript is a non=primitive data types that stores data in key value pairs, used to represent structured and related information.

        * Structured Data
        * Key-Value Pair
        * Reference Type
